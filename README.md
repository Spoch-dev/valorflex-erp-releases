# Valorflex ERP — versiones

Instaladores de Valorflex ERP para Windows y el manifiesto de actualizaciones (`latest.json`) que la app
consulta para avisar de versiones nuevas. El código fuente es privado.

- Descargue el instalador `.exe` de la [última versión](../../releases/latest).
- Las apps instaladas se actualizan solas desde aquí (cada versión va firmada).
